# Decentralized-Options-Exchange

Peer-to-peer cryptocurrency derivatives and options trading platform.

## Project Structure
- `scripts/deploy.sh` — Primary Shell service module
- `src/` — Supporting runtime configuration, retry, and cache utilities
- `tests/` — Unit tests and boundary checks
- `docs/` — Architecture and operational notes
